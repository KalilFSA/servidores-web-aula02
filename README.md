## Resumo da aula
Nesta aula aprendemos sobre servidores web e como funciona a comunicação entre cliente e servidor.

Também aprendemos a diferença entre servidor local e servidor remoto, além dos conceitos de ambiente de desenvolvimento e ambiente de produção.

Nos exercícios, criamos páginas HTML e identificamos o cliente, o servidor e a resposta entregue pelo servidor.

## O que aprendi sobre servidores web

Aprendi que o cliente é responsável por fazer uma solicitação ao servidor através do navegador. O servidor recebe essa solicitação, processa e envia uma resposta para o cliente.

Também aprendi a diferença entre um servidor local, utilizado durante o desenvolvimento e testes, e um servidor remoto, utilizado para disponibilizar um sistema para acesso pela Internet.

Além disso, aprendi conceitos básicos de HTML, HTTP, HTTPS, servidores web e publicação de arquivos no GitHub.
