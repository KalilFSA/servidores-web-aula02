Exercício 3 - Servidor Local x Servidor Remoto

Servidor Local

É um servidor executado no próprio computador do desenvolvedor. Ele é utilizado para testes e desenvolvimento.

Servidor Remoto

É um servidor que está em outro computador, normalmente conectado à Internet, permitindo que outras pessoas acessem o sistema.

Ambiente de Desenvolvimento

É o ambiente utilizado para criar, modificar e testar um sistema antes de disponibilizá-lo para os usuários.

Ambiente de Produção

É o ambiente onde o sistema fica disponível para os usuários finais.

Exemplo prático

Durante os testes uso XAMPP no computador. Depois publico o sistema em um servidor remoto para acesso pela Internet.
